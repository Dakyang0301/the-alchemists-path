# The Alchemist's Path — Course Website

Multi-page course website for The Alchemist's Path: learning roadmap, self-assessment/quiz engine, course levels, glossary, checkout cards, and member pages. Built as reusable components for GoHighLevel.

**Live (Light Blue version):** [https://lightbluealchemist.netlify.app](https://lightbluealchemist.netlify.app)

## Two design versions

| Folder | Version | Pages |
|---|---|---|
| [light-blue/](light-blue) | Light Blue — final design, live on Netlify | 14 pages: home, about, assessment, quiz, courses, levels, how-to-start, glossary, articles, videos, group, dashboard, login, register |
| [dark-blue/](dark-blue) | Dark Blue — earlier design direction | home, about, assessment, book, levels + dark theme |

## Other folders
- [components/](components) — reusable GoHighLevel blocks: global styles, roadmap, assessment engine, checkout cards, and the full combined page
- [tap-deploy/](tap-deploy) — early Light Blue build with animated starfield background, plus brand images (logo, book cover, mockups)

## Tech
HTML · CSS · JavaScript · GoHighLevel · Netlify
